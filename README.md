# Ozee Electrical Hub

Ozee Electrical E-Commerce Website

Detailed Website Requirements & Project Scope

1. Project Overview

The proposed website will be a modern, responsive e-commerce platform for Ozee Electrical, focused on the sale of electrical, lighting, power, and solar products.

The website will allow customers to browse products, view different product variations and prices, add products to their cart, place orders, and contact the business.

The platform will also include a dedicated admin dashboard that allows Ozee Electrical to manage products, prices, stock, orders, services, homepage content, business information, and other website content without needing a developer to make routine changes.

27. Main Goal of the Platform

The final platform should allow Ozee Electrical to operate its online store without depending on the developer for everyday updates.

For example, the owner should be able to log into the admin dashboard and:

Add a new product → Add its image → Add variations → Set prices → Set stock → Publish

Or:

Change phone number → Save → Website updates automatically

Or:

Change homepage video → Upload new video → Save → New video appears on homepage

Or:

Change product price → Edit variation → Save → New price appears on the store

That is the core idea behind the platform.
