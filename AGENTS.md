## Project decisions

- The first release uses the Kinetic glass commerce direction with Manrope body text, Space Grotesk headings, and semantic blue-cyan tokens; this matches Ozee Electrical's stated brand palette and mobile-first shopping audience.
- Storefront interactions are implemented locally first; durable catalog, customer, order, and admin workflows will use Lovable Cloud when those surfaces are added.
